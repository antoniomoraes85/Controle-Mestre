# Catálogo de aulas — primeiro ciclo

O currículo individual é armazenado **somente em `dados/catalogo/aulas_primeiro_ciclo.csv`**, excluído do GitHub público. O arquivo de distribuição privado do titular inclui 125 aulas das listas recebidas para oito disciplinas. Direito Civil aguarda a relação de aulas.

Quando instalar atualização por GitHub, copie essa pasta privada, além de `dados/controle_mestre.db`, da instalação anterior.

Os títulos de aulas recebidos não equivalem a um edital vigente e não devem ser confundidos com conteúdo já estudado.
